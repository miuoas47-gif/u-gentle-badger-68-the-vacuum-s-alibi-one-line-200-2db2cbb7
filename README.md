A robot vacuum's one-line alibi for missing a spot — 115 characters, deadpan, with the punch at the end:

> I skipped that spot on purpose: my sensors classified the dust bunny as a pet, and my warranty forbids eating pets.

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it is 1–200 characters and one line, reads it back to verify, and exits 0. Stdlib only, no arguments, no network, deterministic — every run writes byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
